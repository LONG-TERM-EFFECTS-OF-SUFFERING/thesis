\chapter{Abstract}

YouTube, with 2,530 million monthly users, serves as a primary news source for 35\% of U.S. adults. However, current YouTube analysis tools rely on proprietary, black-box methodologies that limit transparency and reproducibility, creating barriers for academic research requiring verifiable systems.

This thesis develops a web application that \textbf{processes}, \textbf{analyzes} and \textbf{visualizes} YouTube data through an \textbf{auditable data provenance architecture} and \textbf{reproducible processing pipelines}. Recognizing that the application programming interfaces (APIs) of third-party platforms exhibit temporal decay and dynamic result sets, the system ensures data collection transparency by recording complete API request logs, raw JSON payloads, and parameter configurations, while keeping downstream processing traceable: comment normalization follows deterministic, versioned rules, and every sentiment label records the model and prompt version that produced it. The system comprises three integrated components: a data collection module using the YouTube Data API with natural language processing for query translation, a data processing pipeline for cleaning and normalizing responses, and an interactive visualization layer.

The development followed an adapted Scrum framework with iterative two-week sprints and included technology stack selection, system architecture design, API integration with interfaces powered by large language models (LLMs), database implementation and comprehensive testing. All services are containerized using Docker for reproducible deployment.

The resulting application provides a no-cost, transparent alternative to commercial tools, democratizing YouTube data analysis for academic researchers, non-profits and independent investigators. By providing a fully documented methodology and open architecture, this work promotes \textbf{reproducible science} and serves as a \textbf{foundational tool} for research in social media analysis, polarization and information dissemination.
