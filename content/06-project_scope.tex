\chapter{Project scope}
\label{chap:project_scope}

\section{Inclusions}

This section details the specific features, deliverables and technologies that are part of the project.

\subsection{Functionality}

The project delivers a web application that automates the collection, processing, analysis and visualization of data from YouTube. The core functionalities include:

\begin{itemize}
    \item \textbf{Data collection module}: a configurable module collects video and associated comment data directly from the YouTube Data API using specified query filters.

    \item \textbf{AI query module}: a Natural Language Interface that integrates with a pre-trained AI model to translate informal user requests into valid YouTube Data API queries.

    \item \textbf{Data processing pipeline}: the application has a processing pipeline that cleans, normalizes, validates and structures the raw data retrieved from the API.

    \item \textbf{Presentation layer}: a user-facing presentation layer shows the analyzed data in charts.
\end{itemize}

\subsection{Technology}

The specific technology stack was selected and justified during development (Activity~\ref{act:1.1}); the architecture follows these principles:

\begin{itemize}
    \item \textbf{Backend service}: the core application logic and API are developed with a modern web framework, with a relational database for data storage.

    \item \textbf{Frontend service}: a lightweight web server (e.g., Nginx) serves the static frontend assets (HTML, CSS and JavaScript) built from a modern JavaScript framework (e.g., React, Vue).

    \item \textbf{Containerization}: all services (web server, backend application, database) are containerized with Docker to ensure a consistent and reproducible deployment environment.
\end{itemize}

\section{Exclusions}

To maintain a clear focus and ensure the project is achievable within the defined timeframe, the following features and functionalities are explicitly out of scope:

\begin{itemize}
    \item \textbf{Support for other platforms}: data collection and analysis are limited to YouTube. The application does not support any other social media or video platforms (e.g., Facebook, Twitter, TikTok).

    \item \textbf{Training of NLP models}: the project \textbf{integrates} existing, pre-trained models (for sentiment analysis and query translation). The scope does not include the \textbf{training or fine-tuning} of new or custom natural language processing or machine learning models from scratch.

    \item \textbf{Real-time data streaming}: the data collection process is designed to be on-demand based on user queries. The project does not implement real-time or live-streaming data analysis.

    \item \textbf{Long-term storage of YouTube data}: the YouTube API Services Developer Policies allow API data to be stored for at most 30 calendar days \autocite{youtube_api_services_developer_policies}. The application deletes collected YouTube data 30 days after retrieval and does not provide a permanent dataset archive.

    \item \textbf{Native mobile application}: the final deliverable is a web application accessible through standard desktop browsers. The development of native mobile applications for iOS or Android is not included.
\end{itemize}
